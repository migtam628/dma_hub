# DMA Hub

**Status: Design and architecture planning. No product application is implemented.**

This repository is planned to house a cohesive software platform with a public storefront, customer dashboard, administration console, Windows desktop companion, configuration profiles and documented device integrations.

## Design direction

**Concept 3 — Professional Hybrid**: midnight navy surfaces, cyan emphasis, restrained violet secondary accents, clear operational layouts and unified patterns across web and desktop.

## Current documentation

- [Batch 3: Secondary screens, shared states and acceptance criteria](docs/concept-3-batch-3.md)
- [Architecture and phased roadmap](docs/project-roadmap.md)

Earlier Batch 1 and Batch 2 design specifications exist separately and can be added once consolidated/reviewed. No app code, builds or deployment are included in this documentation-first initialization.

## Proposed surfaces

- Public product website / storefront
- Customer account and software library
- Admin product, license and release management
- Windows launcher and diagnostics
- Configuration Studio, device adapters and cloud profiles

## Scope and security

Software/device integrations will use documented interfaces with user permission and verified updates. No unauthorized access, protected game-memory extraction, anti-cheat evasion or covert hardware behaviors are part of the baseline platform.

## Before implementation

Confirm the supported use case/device, review visual screen designs, approve the proposed API/data model, then scaffold applications and establish CI. See the roadmap for staged entry/exit criteria.
